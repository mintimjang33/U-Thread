# 유쓰레드 로컬 워커

사용자 PC에서 상시 실행되는 프로그램. "이미 로그인된 내 세션"으로 대신 작업을 처리해서, 클라우드 API 종량과금 없이(=이미 내고 있는 클로드 정액 구독 안에서) 글 생성 + 쓰레드 자동 참여(검색/좋아요/댓글)를 한다.

계정마다 독립적으로 동작한다 — 페어링 토큰은 유쓰레드 웹 계정별로 발급되고, 클로드 로그인은 이 워커를 실행하는 컴퓨터에서 각자의 클로드 구독 계정으로 한다. 여기(개발자) 계정 정보나 이 세션의 기억에 의존하는 부분은 없다.

- `generate` 작업: 로컬에 설치된 Claude Code CLI(`claude -p`)를 헤드리스로 호출해 텍스트를 생성한다. Gemini API처럼 토큰당 과금되지 않고, 이미 내고 있는 클로드 구독 안에서 처리된다.
- `collect_benchmark` 작업: 로컬 크롬을 별도 프로필로 띄워 threads.net에 로그인된 세션으로 검색·스크롤하며 반응 좋은 글을 수집하고(`ut_benchmark_items`에 저장), 좋아요/AI가 작성한 댓글까지 실제로 남긴다.

## 검증 상태 (2026-08-25)

실제 클로드 구독 계정 + 실제 쓰레드 로그인 세션으로 전 과정 라이브 테스트 완료:
- ✅ `claude -p` 헤드리스 호출 — 정상 동작 확인.
- ✅ 실제 크롬 자동화 — 키워드 검색, 스크롤, 게시물 수집(`ut_benchmark_items` 저장) 확인.
- ✅ 좋아요 실제 클릭 확인.
- ✅ AI가 게시물을 읽고 판단해서 자연스러운 댓글을 실제로 게시하는 것까지 확인.
- ✅ 대시보드의 "워커 종료" 버튼으로 워커 프로세스 + 자동화 크롬 창이 모두 완전히 닫히는 것 확인.

## 필요한 것 (미리 설치되어 있어야 함)

- [Node.js](https://nodejs.org) (LTS 버전)
- Google Chrome
- Claude Code CLI: `npm install -g @anthropic-ai/claude-code` — 그리고 클로드 구독(Pro/Max) 계정 필요
- 유쓰레드 계정 (웹 대시보드에서 페어링 토큰을 발급받아야 함)

## 설정 방법 (최초 1회, 순서대로)

이 `worker` 폴더 전체를 내 컴퓨터로 받은 다음, 아래 배치파일을 순서대로 더블클릭해서 실행한다.

1. **`1_install.bat`** — 필요한 패키지 설치.
2. **`0_claude_login.bat`** — 브라우저가 열리면 **자신의** 클로드 구독 계정으로 로그인. (컴퓨터 1대당, 계정 1개당 한 번만 하면 됨.)
3. **`2_setup.bat`** — 다음 두 가지를 입력:
   - 유쓰레드 웹 API 주소 (기본: `https://u-thread.vercel.app`)
   - 페어링 토큰 — 유쓰레드 웹 대시보드의 **"My 클로드 구독 연결"** 페이지에서 "이용권 발급" 버튼으로 발급받은 코드. **자신의 유쓰레드 계정**에서 발급받은 토큰을 넣어야 그 계정의 작업이 이 워커로 들어온다.

## 실행

**`3_start.bat`**을 더블클릭하면 워커가 백그라운드로 시작되고, 브라우저에 GUI 대시보드(`http://localhost:5757`)가 자동으로 열린다. 여기서 상태 확인, 원본 수집 실행, 재연결, 종료를 버튼으로 할 수 있다.

쓰레드 자동화가 필요한 작업(원본 수집)이 처음 들어오면 별도의 크롬 창이 뜨는데, 그 창에서 자신의 쓰레드 계정으로 로그인해야 한다(최초 1회, 이후엔 그 크롬 프로필에 로그인 상태가 유지됨).

완전히 끄려면 대시보드의 "🛑 워커 종료" 버튼을 누른다 — 워커 프로세스와 자동화 크롬 창이 함께 닫힌다.
