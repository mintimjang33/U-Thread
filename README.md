# 유쓰레드 (U-Thread)

쓰레드(Meta Threads) 콘텐츠 자동화 + 트렌드 인사이트 + BYOK 제휴마케팅 SaaS.

## 실행

```bash
npm install
npm run dev   # http://localhost:3200
```

## 주요 기능

- Google OAuth / 이메일 로그인
- AI 스마트 에디터(원고 작성 / 제휴 마케팅 / 심의 필고) + 멀티 에디터(다중 계정 동시 발행)
- 페르소나 관리(AI 스타일 자동 추출 포함) + 제휴 댓글 템플릿
- 벤치마킹 보관함(폴더, 링크 스크랩, 크롬 익스텐션 연동)
- 트렌드 & 인사이트(데이터랩/구글트렌드/쇼핑트렌드/실시간뉴스)
- Threads OAuth 연동 및 실제 발행, 쿠팡파트너스 상품검색/딥링크
- BYOK Vault(AES-256-GCM 암호화), 구독/결제(모의)
- MCP 서버(`/api/mcp`) — Supabase 데이터 및 주요 기능을 외부에서 직접 다룰 수 있음
